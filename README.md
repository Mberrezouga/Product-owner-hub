# 🎯 Product Owner Hub

A modern, elegant, and comprehensive Product Owner dashboard for managing projects, tasks, budgets, and sprints.

**© 2024 All rights reserved by Malek Berrezouga**

## ✨ Features

- 🔐 **Authentication** - Login/Register + Social Login (Google & Microsoft) + Guest Demo Mode
- 📊 **Dashboard** - Metrics, Charts (Pie, Bar, Progress)
- 📁 **Projects** - Add/Edit/Delete with progress tracking
- 📋 **Kanban Board** - Drag-and-drop tasks between columns
- 📅 **Calendar** - Large, clear calendar with events
- 💰 **Budget Tracker** - Visual budget utilization
- 🔔 **Notifications** - Deadline, budget, and milestone alerts
- 💾 **Data Persistence** - localStorage with Export/Import
- 🌐 **Social Login** - Quick login with Google/Microsoft (Mock & Real modes)

## 🚀 Quick Start

```bash
yarn install
yarn start
```

Visit `http://localhost:3000` and click **"Continue as Guest"**

## 🌐 Deploy to GitHub Pages

See [DEPLOYMENT_GUIDE.md](../DEPLOYMENT_GUIDE.md) for complete instructions.

```bash
yarn deploy
```

## 🔑 Social Login Setup

Social login works in **Mock Mode** by default (no setup required).

For **Real OAuth** setup, see [OAUTH_SETUP_GUIDE.md](../OAUTH_SETUP_GUIDE.md)

## 🎨 Tech Stack

- React 19 + React Router v7
- TailwindCSS + Shadcn UI
- Recharts + @dnd-kit
- localStorage (no backend needed)

Perfect for GitHub Pages hosting! 🚀
